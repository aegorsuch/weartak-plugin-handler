## WearTAK Handler release test

- [ ] Install the APK on a supported Wear OS watch and verify WearTAK can discover Handler.
- [ ] Launch Handler on the watch without ATAK Companion. Start and stop monitoring.
- [ ] Using a stationary setup, confirm no breathing estimate is shown without a periodic signal.
- [ ] With gentle periodic lateral motion, check that an approximate breathing rate appears.
- [ ] Confirm sustained high movement suppresses the breathing estimate and raises a local alert.
- [ ] Exit the activity and confirm monitoring stops. Record watch model, WearTAK version and observations.

Bench checks only; these results do not validate respiratory measurements on animals.
